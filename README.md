# demography-dashboard
# Анализ естественного движения населения по регионам России (2023)

## О проекте
Этот проект посвящен анализу рождаемости, смертности и естественного прироста (убыли) населения в 85 субъектах РФ за 2023 год. 
В ходе работы были выявлены регионы-лидеры по приросту населения, а также регионы с наиболее глубокой демографической ямой.

## Инструменты
* **SQL (DuckDB)** — выгрузка и предварительная обработка данных.
* **DBeaver** — среда для написания SQL-запросов.
* **Power BI** — создание интерактивного дашборда.
* **HTML/JS** — альтернативная версия дашборда для веба.

## Источник данных
* **Первоисточник:** Федеральная служба государственной статистики (Росстат), Демографический ежегодник России.
* **Платформа-агрегатор:** Проект «Точно» (tochno.st). 
* **Исходный файл:** `data_regions_collection_102_v20260313.parquet` (датасет «Социально-экономические показатели регионов России»).
* **Обработка:** Данные за 2023 год были извлечены из Parquet-файла с помощью SQL (DuckDB) и выгружены в CSV для визуализации.

## Основные выводы
1. В 2023 году только в 15 из 85 регионов рождаемость превышала смертность.
2. Наибольший естественный прирост наблюдается в Чеченской Республике (+15,7) и Ингушетии (+11,9).
3. Самая глубокая демографическая убыль зафиксирована в Псковской (-10,0) и Смоленской (-9,4) областях.
